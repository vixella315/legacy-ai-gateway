# Compatibility

## Status

Compatibility inventory only. Physical compatibility is currently unverified.

## Public reference evidence

Public projects demonstrate that some legacy Java ME devices and old Android devices have been used as interfaces or nodes for modern AI systems. Those projects are references, not proof that this repository works on the same hardware.

## Planned compatibility layers

- Java ME / J2ME legacy devices;
- old Android devices;
- modern devices;
- browser clients;
- future constrained interfaces.

## Physical qualification

Later hardware testing must record at minimum:

- device model;
- firmware;
- CLDC/MIDP version where applicable;
- JVM/runtime;
- memory constraints;
- screen/input characteristics;
- character encoding;
- network capability;
- TLS behavior;
- message-size limits;
- response-size limits;
- observed failures.

Emulators must not be treated as substitutes for physical qualification.
